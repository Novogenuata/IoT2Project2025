# IoT2Project2025 - Smart Greenhouse
A smart greenhouse project for our IOT course. Made by Sigourney, Samantha and Alexis

# Inventory 
### Raspberry Pi
- Soil Moisture Sensor
- Water Pump
- Fan
- LED grow lights
- MCP3008
- Relay
- CM chip
### Arduino MKR
- ENV shield
